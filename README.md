# Roadster Rush

A 3D electric-roadster racing game that runs in the browser (desktop + mobile) and is
hosted on GitHub Pages. Plain ES modules + three.js, no build step.

- Play locally: `npx serve .` (or any static server) and open http://localhost:3000
- Team layout and module contracts: [ARCHITECTURE.md](ARCHITECTURE.md)

three.js r160 is vendored in `vendor/` (MIT, see `vendor/THREE-LICENSE`).
